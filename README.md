# 📚 AI Book Scanner MVP

A smart mobile application that scans book covers, performs OCR, searches online, and provides comprehensive book information with AI-powered chat.

---

## 🎯 Project Overview

**Core Idea:**  
📷 Scan Book Cover → 🔤 OCR Reads Text → 🔍 Web Search → 📖 Display Info (Rating, Description, Price, Author, Similar Books) + 💬 AI Chat
